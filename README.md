# tutor-desk-frontend

Кабинет репетитора: Vue 3 + Vite + Tailwind CSS 4.

## Команды

- `bun install` — поставить зависимости
- `bun dev` — дев-сервер (`/api` проксируется на `wrangler dev` бэкенда, порт 8787)
- `bun run build` — проверка типов и сборка
- `bun lint` / `bun lint:fix` — ESLint
- `bun format` / `bun format:check` — Prettier
- `bun check-types` — vue-tsc
- `bun run test` — Vitest
